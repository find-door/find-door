# 검출에서 출입구와 위치를 추정한 개발 평가

2026-11-02 기존 C 검출 기록과 RGB-D에서 출입구를 추정하는 후보를 구현했다.
이전 [정답 ROI 진단](door-state-evaluation.md)과 달리 정답 bbox·위치는 추론 함수에 전달하지 않는다.
기존 단일 문 모델의 개발 자료이며 독립 시험·실물 평가·SLAM 지도 정확도 결과는 아니다.

## 입력·가정·실패 처리

[doorway.py](../src/mapping_semantic/mapping_semantic/doorway.py)는 RGB·정렬 depth·K·문짝 검출 seed를 받는다.
영상 가장자리에서 벽 색과 평면을 추정하고 벽보다 돌출된 두 수직 문틀을 찾는다.
특정 색상·문 폭·world 위치·문 각도를 사용하지 않는다.
균일한 주변 벽, 대체로 수평인 카메라, 양쪽 돌출 문틀이 보이는 경우를 가정한다.
평평한 문틀·가림·여러 출입구 등에서 근거가 부족하면 unavailable을 반환한다.
검출 bbox나 전체 영상을 출입구 bbox로 그대로 반환하는 대체 경로는 없다.

검출은 첫 실험의 C 기록에서 최고 confidence인 문 박스 하나를 고정 규칙으로 선택한다.
모델 추론을 재실행하거나 임계값을 조정하지 않았다.
출입구 추정 후 기존 깊이 모듈로 상태를 판단하고, 모든 함수 실행이 끝난 뒤 정답으로 채점한다.
무검출·추정 실패도 전체 문 프레임 분모에 포함한다.

[door_position.py](../src/mapping_semantic/mapping_semantic/door_position.py)는 추정 bbox 하단의 양끝 광선과
추정 벽 평면의 교점을 평균해 문턱 위치 후보를 구한다.
하단이 문턱에 대응한다는 가정이 필요하며 bbox 오차·가림·기울기에 취약하다.
기록의 관측 시각 `odom←camera` TF로 변환한 뒤 world 원점과 odom 원점이 같은 기존 Gazebo 계약으로 채점했다.
정답 `(0,0,0)`은 오차 계산에만 사용한다. 실제 SLAM map 좌표를 생성·평가한 것은 아니다.

## 결과

원문은 로컬 `experiments/door_probe/estimated-dev-03/results.json`에 보존했다.
검출 기록은 `eval-01/results.json`의 108프레임을 재사용했다.

| 배치 상태 | 전체 문 프레임 | 출입구 추정·상태 정답 | unknown |
|---|---:|---:|---:|
| 닫힘 | 27 | 18 | 9 |
| 반열림 | 27 | 21 | 6 |
| 완전 열림 | 27 | 12 | 15 |
| 합계 | 81 | 51 | 30 |

추정된 출입구의 문틀 IoU≥0.5도 51/81이었다. 상태 오분류는 없었지만 unknown을 실패로 포함해 정확도는 51/81이다.
문 없는 벽 27프레임에서는 C 문 검출이 없어 출입구·위치를 출력하지 않았다.
실행 오류는 0이다. 문 프레임 실패 30개는 무검출 18, 문틀 경계 부족 6, 벽 평면 불확실 6이었다.

위치는 51/81프레임에서 출력됐다. **출력된 경우에 한한** 3D 위치 오차 중앙값은 0.0582m,
최대는 0.0961m 미만이었다. 위치 미출력 30개를 제외한 조건부 오차이며 전체 성공률과 함께 읽어야 한다.
각 조건의 세 RGB가 같으므로 51프레임은 독립적인 51장면이 아니다.
문 상단 잘림·단순 렌더링·단일 재질의 개발 조건도 유지했다.

## 재현과 검증

```bash
OPENBLAS_NUM_THREADS=1 /usr/bin/python3 scripts/door_probe/estimated_benchmark.py \
  --detections experiments/door_probe/eval-01/results.json \
  --output experiments/door_probe/estimated-dev-new
```

[평가기](../scripts/door_probe/estimated_benchmark.py)는 원본 RGB/depth와 사용한 모듈 해시를 보존한다.
기존 결과 폴더를 덮어쓰지 않는다. 원시 파일은 Git 제외다.
출입구 후보의 합성 단위 검사 14개와 문턱 투영 기하 검사 5개를 수행했다.
단위 검사는 다른 색·좁은 문짝 seed·평벽·문틀 부재·가림·모호함·잘못된 입력을 포함한다.

## 남은 연결

출입구 추정은 제한된 외관·기하 가정의 첫 후보이며 일반 문 검출기로 채택한 것이 아니다.
독립 문/장소 시험, 문짝 라벨·학습 필요성 평가, ROS 입력 어댑터와 map 시각 TF,
시간 메모리 연결·마커·저장 서비스, 실제 촬영 자료 평가는 남아 있다.
