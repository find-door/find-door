# 로봇 도착 전 준비 범위

사용자 위임에 따라 구현·검증·커밋·PR·dev 병합과 Notion 동기화를 작업 단위로 진행합니다.
범위는 MVP의 Phase 0–2 소프트웨어 준비입니다. Phase 3–4의 3D·드론 확장은 MVP 이후입니다.

## 작업 묶음과 완료 기준

| 묶음 | 완료 기준 | 상태 |
|---|---|---|
| 반복 지도 평가·루프 비교 | 자동 주행, 지도 오차, 입력 보존, 급변 분석, 테스트·리뷰 | PR #6 dev 병합 |
| 동일 입력 재생 | 기존 SLAM 출력 TF 제거, 원본 보호, 같은 bag ON/OFF 지도 평가 | PR #7 병합·재생 검증 완료 |
| 카메라 융합 | 동기화·깊이·관측시각 TF 검증, 합성 색상 표적 실영상 투영, 객체 병합·저장·복원 | PR #7 병합·통합 검증 완료 |
| 자동 검증 | 외부 연구자원 없이 순수 테스트·문서 링크를 CI로 확인 | PR #7 원격 CI 통과 |
| SLAM 후보 | 실행 가능한 Cartographer 비교, 동일 입력·정답 기반 결과와 선택 범위 기록 | 비교 완료·시뮬 기준선 ADR-0004 |
| 실물 인수 준비 | 실제 센서·TF·보정·독립 정답·성능·정지 동작 확인 절차 | 절차 작성 완료·실물 미검증 |

실제 문·계단·소화기 클래스 인식은 합성 표적 검증과 구분합니다. 사용할 수 있는 공개
모델의 클래스·추론 경로와 데이터 범위를 확인하며, 없는 학습 데이터나 실물 측정을
완료한 것으로 기록하지 않습니다.

## 하드웨어 도착 후 남는 검증

- Jetson/JetPack·실제 센서·드라이버·장착 TF 확인과 카메라 내부/외부 보정 실측.
- 휠 오도메트리·IMU·미끄러짐, 실제 공간의 지도·객체 위치 독립 정답 비교.
- Jetson 처리 속도·열·메모리·전력 및 장시간 안정성, 물리 정지 동작.
- 실물 데모 영상과 사용자의 RViz 화면 확인.
- 연구자원 사용·공개 범위 승인. 저장소 공개 전환이나 라이선스 확정은 임의로 하지 않음.

이 항목들은 소프트웨어 준비와 분리하며, Phase 1·2의 실물 완료 체크는 유지합니다.
