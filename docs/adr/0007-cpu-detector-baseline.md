# ADR-0007: NanoDet CPU 검출 연결 기준선

- **상태:** ✅ 결정 — CPU 개발 기준선, 실물 목표 모델은 유보
- **날짜:** 2026-10-25
- **관련 단계:** Phase 2

## 배경

하드웨어 도착 전에 실제 학습 모델을 실행하고 표준 2D 검출을 투영기에 연결해야 합니다.
현재 설치된 OpenCV DNN CPU로 실행 가능한 공개 모델을 선택합니다.

## 선택지와 비교

| 선택지 | 확인 결과 | 범위 |
|---|---|---|
| 색상 fixture | 실제 Gazebo 영상의 투영 기준점 검증 가능 | 학습 모델 정확도와 분리 |
| OpenCV Zoo NanoDet FP32 | OpenCV 4.5.4 CPU·양성 이미지·ROS 연결 확인 | COCO80 클래스 |
| 별도 학습 모델·Jetson 최적화 | 목표 클래스·성능에 맞게 선택 가능 | 데이터·Jetson 미확보, 이번 성능 비교 안 함 |

## 결정과 이유

NanoDet-m-plus-1.5x_416을 별도 CPU 검출 노드로 제공합니다. 종횡비 보존 letterbox와
정확한 역변환, 클래스별 NMS, 원본 header 유지, 최신 영상 1장 대기를 사용합니다.
모델 경로는 명시해야 하고 매 실행 SHA-256을 기록합니다. 가중치는 저장소에 넣지 않습니다.
상류 코드·LICENSE·NOTICE를 보존하고 수정된 wrapper를 분리합니다.

모델 SHA-256은 `4b82da9944b88577175ee23a459dce2e26e6e4be573def65b1055dc2d9720186`입니다.
공식 모델의 3개 stride·6개 출력 tensor를 실제 실행으로 확인했습니다.
지원 클래스·다운로드 출처·명령은 [검출 기준선](../detector-baseline.md)에 있습니다.

## 포기한 것 / 위험

COCO80에는 문·계단·소화기가 없으며 fire hydrant를 소화기로 취급하지 않습니다.
공개 샘플의 사람 2개 검출은 실행 확인일 뿐 정량 인식 평가가 아닙니다.
Jetson 가속·처리율·열·메모리·실제 대상 데이터 성능을 측정하지 않았습니다.
기본 추론 타이머는 5Hz이며 실제 처리율이나 발행 간격을 보장하지 않습니다. 실제 목표 클래스 데이터를 확보한 뒤
모델·학습·최적화를 선택해야 합니다.

## 검증 방법

모델 없이 실행하는 전처리·후처리·shape·hash 단위검사와 실제 FP32 양성 추론,
ROS header·빈 영상·잘못된 인코딩·입력 중단, 외부 투영까지의 연결을 확인했습니다.
정답·학습·평가 데이터가 분리된 실물 대상 평가를 [인수 절차](../robot-acceptance.md)에 추가합니다.
