# ADR-0001: 개발 플랫폼으로 JetAuto(지상 로봇) 사용

- **상태:** ✅ 결정
- **날짜:** 2026-10-21
- **관련 단계:** Phase 0

## 배경

최종 목표는 실내 정찰 드론이지만, 드론에 2D LiDAR를 달면 기체 기울기 때문에 스캔 평면이 바닥·천장을 찍는 문제가 있다. 매핑 파이프라인 자체를 먼저 검증할 안정적인 플랫폼이 필요하다.

## 선택지와 비교

| 기준 | 핸드헬드 리그 | 지상 로봇 (JetAuto) | 드론 |
|---|---|---|---|
| 스캔 평면 안정성 | 손떨림 있음 | 높음 (수평 유지) | 낮음 (기울기) |
| 오도메트리 | 없음 | 휠 오도메트리 + IMU | IMU/VIO 의존 |
| 시뮬레이션 | 별도 제작 필요 | 연구과제 `wf_gazebo` 재사용 가능 | 별도 구축 필요 |
| 하드웨어 확보 | 별도 제작 | 연구과제 로봇 사용 | 미확보 |

## 결정과 이유

JetAuto(지상 로봇)를 사용한다. 연구과제에서 쓰는 로봇과 Gazebo 시뮬레이션을 재사용할 수 있고, 스캔 평면이 안정적이어서 SLAM·시맨틱 매핑을 먼저 검증하기 좋다.

## 포기한 것 / 위험

- 드론 고유 문제(기울기, 오도메트리 부재, 진동)는 Phase 4까지 미뤄진다
- 연구과제 자원 사용·공개 범위는 교수님 확인이 필요하다
- 메카넘 바퀴 미끄러짐으로 오도메트리 오차가 클 수 있다

## 검증 방법

Phase 0 완료 조건(실내 world에서 시뮬레이션 주행)과 Phase 1 지도 정확도 측정으로 확인.
