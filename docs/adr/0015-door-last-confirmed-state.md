# ADR-0015: 마지막 문 확인 상태와 현재 관측 유효성 분리

- **상태:** ✅ 결정 — 사용자 요청에 따른 지도 표시·저장 확장
- **날짜:** 2026-11-03
- **관련 단계:** 건물 내부 문 순찰 후속 수정

## 배경

[첫 건물 순찰](../door-patrol.md)은 문 위치 네 개를 저장했으나 관측 후 2초 TTL이 지나면
상태가 모두 unknown이 되어 마지막으로 확인한 열림/닫힘이 지도에서 사라졌다.
사용자는 마지막 확인 결과를 보존하고 현재 관측 여부를 별도 표시하도록 수정·재시뮬레이션을 요청했다.

## 선택지와 비교

| 선택 | 장점 | 제약 |
|---|---|---|
| TTL만 늘림 | 변경 작음 | 오래된 상태를 현재 상태로 해석하기 쉬움 |
| state를 마지막 상태로 덮어씀 | 색 유지 | 기존 현재 관측 평가·unknown 의미를 훼손 |
| 현재 판단과 마지막 확정 이력 분리 | 과거 확인과 현재 유효성을 함께 전달 | 저장 schema·마커·영상 표시 확장 필요 |

## 결정과 이유

`state`는 기존의 현재 판단 의미를 유지한다. TTL·불확실 관측·확정 전 반대 관측에서 unknown이 된다.
`last_confirmed_state`와 `last_confirmed_stamp_ns`를 추가해 마지막 시간 종합 확정 결과와 실제 관측 시각을 보존한다.
처음에는 unknown/null이며 연속 근거가 충족된 open/closed에서만 갱신한다.
중복·unknown·TTL은 과거 확정 상태나 시각을 갱신하지 않는다. 지도/시간 epoch 초기화는 객체와 이력 모두 지운다.

조회 시 현재 ROS 시각으로 observation_status와 age를 파생한다.

| 상태 | 의미 |
|---|---|
| confirmed | 신선한 현재 관측에서 open/closed 확정 |
| uncertain | 관측은 신선하지만 현재 state는 unknown |
| stale | 마지막 유효 문 관측 후 TTL 초과 |

observation_age_sec와 last_confirmed_age_sec는 각각 마지막 문 관측과 마지막 확정의 경과 시간이다.
ROS 출력은 door_map_schema_version=2와 위 파생 필드를 포함한다.
RViz 색은 마지막 확정 결과, 구형 마커 밝기는 현재 관측 상태를 나타낸다.
텍스트는 last:상태·confirmed/uncertain/stale·확정 후 경과 시간을 표시한다.
확정 이력이 없는 문은 unconfirmed로 표시한다. 영상은 마지막 상태 개수와 현재 관측 개수를 별도 집계한다.

DoorMap과 세션은 schema2로 저장한다. 상대 age/status는 저장하지 않고 조회 시 다시 계산한다.
저장된 현재 state는 저장 시의 TTL을 반영하며 마지막 확정 필드와 함께 보존한다.
schema1은 읽기 전용 이관을 지원한다. 기존 known만 해당 관측 시각의 확인으로 복원하며
이미 unknown인 예전 파일에서 유실된 과거 상태를 만들어 넣지 않는다.
불일치 시각·상태·추가 키는 원자적으로 거부하며 투표 근거는 복원하지 않는다.

## 포기한 것 / 위험

과거 확인은 현재 문 상태를 보장하지 않는다. 현재 확인과 과거 이력을 혼합해 상태 정확도를 계산하지 않는다.
새 연속 관측이 확정되기 전까지 마지막 상태는 이전 값이며, 텍스트·밝기·age로 이를 구분해야 한다.
이전 schema1만 지원하는 읽기 도구는 새 파일을 거부한다. schema2를 이해하는 현재 코드로 읽어야 한다.

## 검증 방법

TTL·중복·불확실 관측·반대 상태 전이·저장/로드·schema1 안전 이관·reset의 단위 검사를 수행한다.
실제 ROS Node에서 마커·JSON·schema2 저장/로드와 만료된 마지막 정보의 보존을 확인한다.
동일 건물·경로·모델·문턱으로 headless 순찰과 GUI 녹화를 다시 실행한다.
현재 state의 신선한 관측으로 기존 문별 평가를 하고, 종료 시 state=unknown/stale와
last_confirmed_state 보존을 별도 검사한다. [재시험 결과](../door-last-observation.md)를 따른다.
